===============================================================================
                       Mfklixo (Modern Kloxo-MR)
                       Installation & Setup Guide
===============================================================================

This guide explains how to install and setup Mfklixo on modern Linux distributions,
including Ubuntu / Debian as well as RHEL / CentOS / AlmaLinux / Rocky Linux.

-------------------------------------------------------------------------------
1. Pre-installation Requirements
-------------------------------------------------------------------------------

A clean, fresh server installation is strongly recommended.
Run the commands below with root privileges.

A. On Ubuntu / Debian:
----------------------
    apt-get update -y && apt-get upgrade -y
    apt-get install -y git curl wget zip unzip tar systemd \
                       php-cli php-fpm php-mysql php-mbstring php-xml \
                       mariadb-server nginx apache2

B. On RHEL / CentOS / AlmaLinux / Rocky Linux:
----------------------------------------------
    yum update -y
    yum install -y git curl wget zip unzip yum-utils epel-release \
                   systemd mariadb-server nginx httpd

-------------------------------------------------------------------------------
2. Cloning & Setting up Mfklixo
-------------------------------------------------------------------------------

    mkdir -p /usr/local/lxlabs
    cd /usr/local/lxlabs
    git clone -b modernize-kloxo https://github.com/feizezadeh/Mfklixo.git kloxo
    cd /usr/local/lxlabs/kloxo

-------------------------------------------------------------------------------
3. Initial Configuration & Service Initialization
-------------------------------------------------------------------------------

A. Database Setup (MariaDB):
----------------------------
    # Start and enable MariaDB
    systemctl enable mariadb
    systemctl start mariadb

    # Optional: Select specific MariaDB version (e.g. 10.11 or 11.4 LTS)
    sh /usr/local/lxlabs/kloxo/pscript/mariadb-upgrade 10.11

B. Web Server Setup:
--------------------
    # Choose your preferred web server stack:

    # 1) Dual Proxy: Apache (Backend) + Nginx (Frontend) [Recommended]
    sh /usr/local/lxlabs/kloxo/pscript/switchserver --class=web --driver=apache_nginx

    # 2) Standalone Nginx:
    sh /usr/local/lxlabs/kloxo/pscript/switchserver --class=web --driver=nginx

    # 3) Standalone Apache:
    sh /usr/local/lxlabs/kloxo/pscript/switchserver --class=web --driver=apache

C. Generate Initial Configs & Restart Services:
-----------------------------------------------
    sh /usr/local/lxlabs/kloxo/bin/fix/fixweb.php --target=defaults
    sh /usr/local/lxlabs/kloxo/pscript/restart-web -y

-------------------------------------------------------------------------------
4. Accessing the Panel
-------------------------------------------------------------------------------

Once services are running, access the control panel via browser:

    URL:      http://<YOUR_SERVER_IP>:7778/
    or SSL:   https://<YOUR_SERVER_IP>:7777/

    Default Username: admin
    Default Password: (set during initialization or reset via script)

To reset the admin password if needed:
    php /usr/local/lxlabs/kloxo/bin/common/misc/reset-mysql-root-password.php

-------------------------------------------------------------------------------
5. Handy Maintenance Commands
-------------------------------------------------------------------------------

- Switch PHP Branch:
    sh /usr/local/lxlabs/kloxo/pscript/set-php-branch php82

- Upgrade / Switch MariaDB:
    sh /usr/local/lxlabs/kloxo/pscript/mariadb-upgrade 11.4

- Fix Web Configurations:
    sh /usr/local/lxlabs/kloxo/bin/fix/fixweb.php

- Restart All Web Services:
    sh /usr/local/lxlabs/kloxo/pscript/restart-web -y

- Restart Database:
    sh /usr/local/lxlabs/kloxo/pscript/restart-mysql
