===============================================================================
                       Mfklixo (Next-Gen Cloud Panel)
                       Installation & Quickstart Guide
===============================================================================

Mfklixo is a high-performance modern web hosting control panel combining:
  • Rust Core Daemon (mfklixo-core) with high-speed Axum REST API (Port 7788)
  • Next.js 15 Dark-Mode Glassmorphism Dashboard (Port 3000 via Nginx 7777)
  • Reverse-Proxy Web Server: Nginx (80/443) -> Apache 2.4 (8080)
  • Database: MariaDB 10.11+ LTS with phpMyAdmin 5.2.2 web studio
  • Mail Suite: Postfix + Dovecot + Roundcube Webmail 1.6.10
  • Multi-PHP Manager: Version switcher, native module toggle & php.ini editor
  • Automated SSL Engine: Let's Encrypt 1-Click issuance, auto-renewals & custom certs
  • DirectAdmin CustomBuild Studio: Software stack recompiler, options.conf & conf rewriter

Repository: https://github.com/feizezadeh/Mfklixo
Branch:     modernize-kloxo

-------------------------------------------------------------------------------
1. Fast Automated Installation (Recommended)
-------------------------------------------------------------------------------

On a clean Ubuntu 22.04 / 24.04 LTS or Debian 12 server:

    curl -fsSL https://raw.githubusercontent.com/feizezadeh/Mfklixo/modernize-kloxo/install.sh | sudo bash

The installer will automatically:
  1. Install system prerequisites (Rust, Node.js 20, Nginx, Apache, MariaDB, PHP)
  2. Build and install mfklixo-core Rust daemon
  3. Deploy Next.js modern control panel
  4. Install phpMyAdmin 5.2.2 and Roundcube Webmail 1.6.10
  5. Setup dual-access routing (Port 80/443 domains + Port 7777 control panel)
  6. Enable and start all Systemd service daemons

-------------------------------------------------------------------------------
2. Manual Step-by-Step Installation
-------------------------------------------------------------------------------

Step 1: Install System Packages
--------------------------------
On Ubuntu / Debian:
    sudo apt-get update -y
    sudo apt-get install -y git curl wget tar gzip zip unzip build-essential \
                            mariadb-server nginx apache2 libapache2-mod-php \
                            php-cli php-fpm php-mysql php-mbstring php-xml \
                            php-curl php-zip php-intl php-gd composer \
                            certbot python3-certbot-nginx python3-certbot-apache

Step 2: Install Node.js 20 LTS & Rust Toolchain
------------------------------------------------
    # Node.js 20
    curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -
    sudo apt-get install -y nodejs

    # Rust
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
    source "$HOME/.cargo/env"

Step 3: Clone Repository
------------------------
    sudo mkdir -p /usr/local/lxlabs
    cd /usr/local/lxlabs
    sudo git clone -b modernize-kloxo https://github.com/feizezadeh/Mfklixo.git kloxo
    cd /usr/local/lxlabs/kloxo

Step 4: Build & Install Rust Core Daemon
----------------------------------------
    cargo build --release
    sudo cp target/release/mfklixo-core /usr/local/lxlabs/kloxo/bin/mfklixo-core
    sudo chmod +x /usr/local/lxlabs/kloxo/bin/mfklixo-core

    # Install Systemd service
    sudo cp kloxo/init/mfklixo-core.service /etc/systemd/system/
    sudo systemctl daemon-reload
    sudo systemctl enable --now mfklixo-core.service

Step 5: Build & Install Next.js Dashboard
-----------------------------------------
    cd /usr/local/lxlabs/kloxo/frontend
    npm install
    npm run build

    # Install Dashboard Systemd service
    sudo cp ../kloxo/init/kloxo-dashboard.service /etc/systemd/system/
    sudo systemctl daemon-reload
    sudo systemctl enable --now kloxo-dashboard.service

Step 6: Install phpMyAdmin 5.2.2
--------------------------------
    sudo mkdir -p /usr/share/phpmyadmin
    curl -sL https://files.phpmyadmin.net/phpMyAdmin/5.2.2/phpMyAdmin-5.2.2-all-languages.tar.gz \
      | sudo tar -xz -C /usr/share/phpmyadmin --strip-components=1

    # Link Apache configuration
    sudo cp /usr/local/lxlabs/kloxo/kloxo/init/phpmyadmin.conf /etc/apache2/conf-available/
    sudo a2enconf phpmyadmin
    sudo systemctl reload apache2

Step 7: Install Roundcube Webmail 1.6.10
----------------------------------------
    sudo mkdir -p /usr/share/roundcube
    curl -sL https://github.com/roundcube/roundcubemail/releases/download/1.6.10/roundcubemail-1.6.10-complete.tar.gz \
      | sudo tar -xz -C /usr/share/roundcube --strip-components=1

    # Link Apache configuration
    sudo cp /usr/local/lxlabs/kloxo/kloxo/init/roundcube.conf /etc/apache2/conf-available/
    sudo a2enconf roundcube
    sudo systemctl reload apache2

4. Systemd Daemons & Service Management
-------------------------------------------------------------------------------

Check status of all Mfklixo daemons:
    sudo systemctl status mfklixo-core.service      # Rust Backend Core (Port 7788)
    sudo systemctl status kloxo-dashboard.service    # Next.js Frontend (Port 3000)
    sudo systemctl status kloxo-web.service          # Nginx Gateway (Port 7777)
    sudo systemctl status nginx                      # Public Web Proxy (Port 80/443)
    sudo systemctl status apache2                    # Web Backend (Port 8080)
    sudo systemctl status mariadb                    # Database Server

Restart all Mfklixo stack:
    sudo systemctl restart mfklixo-core kloxo-dashboard kloxo-web nginx apache2

-------------------------------------------------------------------------------
5. Decommissioning Old Legacy Core
-------------------------------------------------------------------------------

Mfklixo completely eliminates the ancient PHP 5/lxphp core.
Ensure old services are permanently disabled:
    sudo systemctl stop kloxo-php kloxo-wrap 2>/dev/null || true
    sudo systemctl disable kloxo-php kloxo-wrap 2>/dev/null || true
    sudo rm -f /etc/systemd/system/kloxo-php.service /etc/systemd/system/kloxo-wrap.service
    sudo systemctl daemon-reload

All operations now execute through the high-performance Rust daemon on port 7788.

6. DirectAdmin-Style CustomBuild & Let's Encrypt SSL
-------------------------------------------------------------------------------

Mfklixo features a native DirectAdmin-style CustomBuild stack engine:
  • Web Interface:
      Navigate to: https://<YOUR_SERVER_IP>:7777/custombuild
      - Live component versions vs latest releases (Nginx, Apache, PHP, MariaDB, etc.)
      - options.conf stack configuration (/usr/local/lxlabs/kloxo/etc/custombuild.json)
      - 1-Click build actions: Update Versions, Rewrite Confs, Build Stack
      - Real-time build log streaming console

  • SSL & Let's Encrypt Management:
      Navigate to: https://<YOUR_SERVER_IP>:7777/ssl
      - 1-Click Let's Encrypt automated issuance with www alias & HTTP->HTTPS force
      - Auto-renewal status tracking and 1-Click renewal button
      - Self-signed certificate generator & custom PEM/CRT/KEY installer
